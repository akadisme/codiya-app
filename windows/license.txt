코디야 전화팝업 (PC 프로그램) 이용 안내

1. 이 프로그램이 하는 일
 - 코디야 앱이 설치된 휴대폰에 전화가 오면, PC 화면 맨 앞에 고객 메모 창을 띄워요.
 - PC를 켜면 자동으로 실행되어 화면 오른쪽 아래(시계 옆)에 작은 아이콘으로 켜져 있어요.
 - 설치하면 바탕화면에 "코디야 전화팝업" 아이콘이 만들어져요.
   아이콘을 누르면 코디야 홈페이지(codiya.kr)가 열려요. 필요 없으면 아이콘은 지워도 돼요.

2. 광고 안내 (꼭 읽어 주세요)
 - 이 프로그램은 화면 오른쪽 아래에 코디야가 정한 광고·안내 창을 잠깐 보여줄 수 있어요.
 - 광고 창에는 "광고" 표시가 붙고, 하루에 몇 번으로 횟수를 제한해요.
 - 광고 창의 [닫기] 또는 [오늘 하루 안 보기]를 누르면 바로 닫혀요.
 - 전화팝업 창이 떠 있을 때는 광고가 뜨지 않아요.

3. 자동 업데이트
 - 새 버전이 나오면 프로그램이 스스로 받아서 조용히 설치해요. 다시 받을 필요가 없어요.

4. 지우는 방법
 - 윈도우 설정 → 앱 → 설치된 앱 → "코디야 전화팝업" → 제거

위 내용(광고 창 표시 포함)에 동의하시면 [동의합니다]를 선택하고 다음으로 넘어가 주세요.
